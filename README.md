# prosekit-extension-template

[![NPM version](https://img.shields.io/npm/v/prosekit-extension-youtube?color=a1b858&label=)](https://www.npmjs.com/package/prosekit-extension-youtube)

A template for building a [ProseKit](https://prosekit.dev) extension and publishing it to npm. The example extension here embeds YouTube videos.

> Published to npm as `prosekit-extension-youtube`. When you use this template, rename the package in `package.json` to your own.

## Project structure

- `src/` — the extension source code
- `dist/` — the bundled extension (ESM + type declarations), generated by `pnpm build`
- `test/` — browser-based tests with [Vitest](https://vitest.dev/) + [Playwright](https://vitest.dev/config/browser/playwright)
- `website/` — a small Vite app for developing and demoing the extension
- `website/dist/` — the built demo website, generated by `pnpm build`

## Development

```bash
git clone https://github.com/prosekit/prosekit-extension-youtube.git
pnpm install

pnpm dev        # start the demo website
pnpm build      # bundle the extension and build the website
pnpm test       # run browser tests
pnpm lint       # lint with ESLint
pnpm fix        # auto-fix with ESLint + Prettier
pnpm typecheck  # type-check with tsc
```

## Usage

Add the extension to your editor:

```ts
import { defineBasicExtension } from '@prosekit/basic'
import { union } from '@prosekit/core'
import { defineYoutube } from 'prosekit-extension-youtube'

const extension = union(defineBasicExtension(), defineYoutube())
```

## Publishing

This repo uses [release-please](https://github.com/googleapis/release-please-action) to publish to npm. Merging the release PR it opens tags a new version and runs `pnpm build && pnpm publish`.
